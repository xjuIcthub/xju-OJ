# server 许可证边界

`server/` 合并的是两个历史源码树，不把许可证文本合并成一份：

| 路径 | 许可证 | 处理规则 |
|---|---|---|
| `server/judge-server/LICENSE` | SATA | 随 JudgeServer 源码保留；版权和上游项目 URL 不改 |
| `server/judger/LICENSE` | SATA | 随 Judger 源码保留；版权和上游项目 URL 不改 |

两份 SATA 文本的原始内容均已在阶段 00 基线提交中纳管。本文件只说明边界，不替换、缩短或重新解释许可证条款。第三方依赖和 bindings 的附带许可证仍以各自目录中的文件为准。
